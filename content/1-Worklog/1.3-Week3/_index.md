## Week 3 Goals

* Understand the deployment and management process of Amazon EC2 on both Linux and Windows operating systems.
* Master Amazon EC2 administrative operations such as changing the Instance Type, creating Amazon EBS Snapshots, and Custom AMIs.
* Deploy a user management application on Amazon Linux 2023 and Windows Server.
* Learn the backup, recovery, and management process of EC2 in a real-world environment.
* Practice skills in deployment, operation, and resource cleanup to optimize costs during practice.

## Week 3 Achievements

### Knowledge

* Understood the deployment and management process of Amazon EC2 on both Linux and Windows operating systems.
* Grasped Amazon EC2 administrative operations such as changing the Instance Type, creating Amazon EBS Snapshots, and Custom AMIs.
* Understood the backup, recovery, and management process of EC2 via Amazon EBS Snapshots and Amazon Machine Images (AMIs).
* Understood the process of deploying web applications on Amazon EC2 with both Linux and Windows environments.

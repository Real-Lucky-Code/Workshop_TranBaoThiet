## Kết quả đạt được tuần 3

### Về kiến thức

* Hiểu quy trình triển khai và quản lý Amazon EC2 trên cả hệ điều hành Linux và Windows.
* Nắm được các thao tác quản trị Amazon EC2 như thay đổi Instance Type, tạo Amazon EBS Snapshots và Custom AMI.
* Hiểu quy trình sao lưu, khôi phục và quản lý EC2 thông qua Amazon EBS Snapshots và Amazon Machine Images (AMI).
* Hiểu quy trình triển khai ứng dụng web trên Amazon EC2 với hai môi trường Linux và Windows.

### Về môi trường thực hành

* Triển khai thành công Amazon Linux 2023 EC2 Instance và Windows Server 2025 EC2 Instance.
* Kết nối và quản lý EC2 thông qua SSH và Remote Desktop Protocol (RDP).
* Thiết lập thành công môi trường LAMP Web Server trên Amazon Linux 2023.
* Cài đặt Node.js và XAMPP trên Windows Server phục vụ việc triển khai ứng dụng.

### Về triển khai ứng dụng

* Triển khai thành công ứng dụng quản lý người dùng trên Amazon Linux 2023.
* Triển khai thành công ứng dụng Node.js trên Windows Server.
* Kiểm tra và xác nhận ứng dụng hoạt động ổn định trên cả hai môi trường Linux và Windows.

### Về kỹ năng

* Rèn luyện kỹ năng quản trị và vận hành Amazon EC2 trên nhiều hệ điều hành.
* Thực hành tạo Amazon EBS Snapshots, Custom AMI và khôi phục quyền truy cập cho EC2 Instances.
* Nâng cao kỹ năng triển khai ứng dụng trên môi trường Linux và Windows trong AWS.
* Hình thành quy trình kiểm tra, triển khai và dọn dẹp tài nguyên sau mỗi bài thực hành nhằm tối ưu chi phí.

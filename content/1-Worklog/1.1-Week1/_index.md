## Week 1 Goals

* Connect and become familiar with the culture, members, and mentors in the **First Cloud AI Journey (FCAJ)** program.
* Understand the program's operating discipline and internship regulations.
* Gain an overview of AWS Cloud Computing and its core service groups, including:
  * Compute
  * Storage
  * Networking
  * Database
* Become familiar with the AWS Management Console and learn how to manage AWS account costs using AWS Budgets.

## Week 1 Achievements

### Knowledge

* Understood the concept of Cloud Computing and the role of AWS.
* Understood the functions of the core AWS service groups:
  * Compute
  * Storage
  * Networking
  * Database
* Understood how AWS services are organized and managed through the AWS Management Console.

### Practice Environment

* Successfully created an AWS Free Tier account for learning and hands-on practice.
* Became familiar with the AWS Management Console and learned how to access and navigate AWS services.
* Completed the AWS environment setup, making it ready for the upcoming hands-on practice sessions.

### Cost Management

* Configured AWS Budgets to monitor resource usage and receive alerts when costs exceed the defined threshold.
* Understood the importance of cost management and the safe use of the AWS Free Tier.
* Successfully completed all five AWS Credits missions and received a total of **$200 AWS Credit** for future hands-on practice.

### Skills

* Gained initial experience in provisioning and cleaning up AWS resources to avoid unexpected charges.
* Strengthened self-learning skills through the program's learning materials and hands-on exercises.
* Developed the habit of managing AWS resources, monitoring costs, and updating the weekly worklog in accordance with the internship program regulations.

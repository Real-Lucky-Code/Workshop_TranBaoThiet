## Introduction

Throughout the **12 weeks** of participating in the **First Cloud AI Journey (FCAJ)** program, I have step-by-step explored and practiced services on the **Amazon Web Services (AWS)** platform, from foundational knowledge of cloud computing to deploying and operating a complete Web application on the AWS Cloud environment.

The initial phase focused on getting familiar with core services such as **IAM, VPC, EC2, RDS, AWS Backup, Storage Gateway, CloudWatch, AWS CLI**, and other supporting services. After that, I applied the learned knowledge to build the project **Online Sports Field Booking System**, deployed the application on the AWS infrastructure, and finalized the summary report of the internship program.

Below is the summary of the work content by each week:

---

**Week 1:** [Getting familiar with AWS, cloud computing, core services, and setting up the practice environment.](1.1-week1/)

**Week 2:** [Access management with AWS IAM and building basic network infrastructure on AWS.](1.2-week2/)

**Week 3:** [Deploying and managing Amazon EC2 on Windows and Linux, and practicing application deployment.](1.3-week3/)

**Week 4:** [Deploying applications with Amazon EC2, Amazon RDS, and practicing data backup and recovery.](1.4-week4/)

**Week 5:** [Building connectivity between VPCs using VPC Peering and AWS Transit Gateway.](1.5-week5/)

**Week 6:** [Practicing AWS Backup and AWS Storage Gateway to serve data backup and storage.](1.6-week6/)

**Week 7:** [Cost management with AWS Budgets and system monitoring using Amazon CloudWatch.](1.7-week7/)

**Week 8:** [Installing, configuring, and managing AWS resources through the AWS CLI.](1.8-week8/)

**Week 9:** [Initializing the Online Sports Field Booking Web project: technology selection and architectural design on AWS Cloud.](1.9-week9/)

**Week 10:** [Project development: building the database, security, and core Backend functions.](1.10-week10/)

**Week 11:** [Project development: finalizing workflows, payment integration, user interface, and system testing.](1.11-week11/)

**Week 12:** [Deploying the project onto the AWS Cloud infrastructure, testing, optimizing, and finalizing the summary report.](1.12-week12/)

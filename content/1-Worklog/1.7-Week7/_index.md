## Week 7 Goals

* Understand the mechanism of cost management and tracking on AWS through AWS Budgets.
* Grasp how to monitor resources and system performance using Amazon CloudWatch.
* Practice building various types of Budgets, Metrics, Logs, Alarms, and Dashboards.
* Understand the process of monitoring, analyzing, and alerting in system operations on AWS.
* Develop skills in cost tracking, resource monitoring, and operational optimization on the AWS platform.

## Week 7 Achievements

### Knowledge

* Understood the cost management mechanism on AWS through AWS Budgets.
* Grasped the functions and usage of different budget types, such as Cost Budget, Usage Budget, Reservation Utilization Budget, and Savings Plans Budget.
* Understood the operating principles of Amazon CloudWatch in monitoring resources and system performance.
* Grasped the process of collecting, analyzing, and visualizing data through Metrics, Logs, Alarms, and Dashboards.

### Practice Environment

* Successfully set up various types of Budgets to serve cost and resource usage tracking.
* Deployed a monitoring environment using Amazon CloudWatch.
* Practiced analyzing Metrics, Logs, and building Dashboards to monitor the system.
* Set up CloudWatch Alarms to automatically alert when the system exceeds the configured thresholds.

### Deployment

* Configured Cost Budget, Usage Budget, Reservation Utilization Budget, and Savings Plans Budget.
* Performed data queries and analysis using CloudWatch Logs Insights.
* Deployed CloudWatch Metric Filters to convert Log data into Metrics.
* Built CloudWatch Dashboards to visualize system status and performance.
* Reviewed and cleaned up all resources after completing the lab to avoid incurring costs.

### Skills

* Practiced cost management and optimization skills on the AWS platform.
* Improved skills in monitoring, analyzing Logs, and tracking system performance using Amazon CloudWatch.
* Practiced building an automated alerting system through CloudWatch Alarms.
* Formed a monitoring, operation, and resource cleanup workflow according to best practices on AWS.
